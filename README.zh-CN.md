# 🌸 Lolia Bloom（洛链绽放）

采用粉色主题的 洛链映射（Lolia FRP）Windows 桌面隧道管理客户端。

[English](README.md) | [简体中文](README.zh-CN.md)

![Lolia Bloom Windows 实际界面](https://github.com/kkbbzjh/LoliaBloom/releases/download/v0.4.3/LoliaBloom-screenshot.png)

## 功能特色

- **云端创建隧道**：选择节点，创建 TCP、UDP、HTTP、HTTPS 隧道。
- **记住登录**：点击登录即可跳转官方授权，支持 OAuth PKCE、Windows 加密保存与自动刷新令牌。
- **官方流量统计**：显示累计流量，并根据服务端更新时间估算速度。
- **签到中心**：手动签到，程序运行时可每小时检查自动签到；授权限制会显示官方错误。

- **粉色管理界面**：清晰展示隧道列表，直接启动或停止单条隧道。
- **隧道详情**：查看协议、节点、本地地址、远程地址和连接状态。
- **独立后台服务**：关闭程序窗口后，隧道进程仍可继续运行。
- **一键安装服务**：在程序内申请管理员权限，安装或卸载 Windows Service。
- **开机自动连接**：为每条隧道设置是否随后台服务自动启动。
- **Windows x64 绿色版**：解压即可打开，内置 .NET 运行环境。
